HOW IT WORKS

SMTP message flow

1
Compose

Enter recipient, subject and message.

2
Web application

The browser sends the message to the Node.js backend.

3
SMTP server

Nodemailer connects and submits the email using SMTP.

4
Recipient mail server

The email is routed toward the recipient's mailbox.

Protocol note

SMTP is used to submit and relay outgoing email. IMAP or POP3 is typically used to retrieve messages.
